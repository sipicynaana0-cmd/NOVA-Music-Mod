# NOVA — модификация Яндекс Музыки

Полная переделка интерфейса Яндекс Музыки для ПК: тёмная фиолетовая тема, видеофон, умные функции.

## Установка

1. Скачай `NOVA_v6.37_Setup.exe` из [Releases](https://github.com/sipicynaana0-cmd/NOVA-Music-Mod/releases/latest)
2. Запусти установщик — права администратора не нужны
3. Ярлык появится на рабочем столе и в меню «Пуск»

## Возможности

- Тёмная фиолетовая тема с бирюзовыми акцентами
- Видеофон под интерфейсом
- Режим игры: окно сворачивается в маленькую перетаскиваемую плашку
- Context History: статистика музыка × приложения (локально, с согласия)
- Без повторов за сессию (по ID треков)
- Анти-тренд: скип чарт-хитов
- Дизлайки навсегда
- Мини-плеер с кнопками
- Авто-проверка обновлений раз в 30 минут

## Обновления

Приложение само проверяет `update.json` в этом репозитории. Когда версия здесь выше установленной — в доке NOVA начинает мигать кнопка «Обновить мод» со списком изменений и ссылкой на новый установщик.

## Приватность

Все данные (история, настройки) хранятся локально. Контекстный логгер выключен по умолчанию и собирает только имя процесса (не заголовки окон, не ввод, не контент).
